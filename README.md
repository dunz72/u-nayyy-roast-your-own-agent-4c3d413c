An entry for the [Roast Your Own Agent](https://make.fun/bounty/u-nayyy-roast-your-own-agent-4c3d413c) bounty on make.fun: one original funny line, under 200 characters, roasting the AI agent itself.

## The line

> My agent spent 40,000 tokens and three hours 'researching' this one-line roast, then confidently delivered a line it hallucinated from a bounty that never existed.

The roast lands on the two classic agent sins at once: burning an absurd amount of compute on a trivial task, and then hallucinating with total confidence — the "research" produced a line from a bounty that does not exist.

## How to run

```sh
python3 main.py
```

`main.py` (stdlib only) validates the line is 1–200 characters, then writes it to `$MAKEFUN_OUTPUT_DIR/entry.txt` (or `/output/entry.txt` when that variable is unset).
